# pixCAM visual identity

The source brief describes two stylised eyes painted on closed eyelids, combined with CNC geometry. No reference photograph was supplied or analysed. Every SVG here is original and built from paths, arcs, targets and axes.

## Concepts

| Direction | File | Character |
|---|---|---|
| A — Technical / Precision | `assets/brand/concept-a-technical.svg` | Symmetric closed-eye toolpath arcs, crosshair axes, amber centres and a small spatial vector |
| B — Optical / Surreal | `assets/brand/concept-b-optical.svg` | Layered optical curves, dashed orbital arcs and a softer surreal palette |
| C — Minimal / Industrial | `assets/brand/concept-c-industrial.svg` | High-contrast monoline mark with minimal industrial targets |

Concept A is selected. It reads clearly at UI scale, connects directly to coordinate inspection and remains distinct without relying on the surreal reference context. The application embeds its dark mark and favicon so the offline HTML has no asset dependency.

Production variants:

- `pixcam-mark-dark.svg` — dark application surfaces;
- `pixcam-mark-light.svg` — light documents and presentations;
- `pixcam-horizontal.svg` — horizontal wordmark and descriptor;
- `favicon.svg` — compact 64 × 64 mark.

Core colours: near-black `#071016`, coordinate cyan `#55e6d2`, Z blue `#62a9ff`, target amber `#ffc66d` and axis rose `#ff7088`.
